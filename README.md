# ⌚ WatchCharm — Exclusive Timepieces

A sophisticated and fully responsive landing page for a luxury watch boutique. This project was developed as a collaborative effort where I served as the Team Lead, focusing on premium UI/UX and modern frontend standards.

## 👑 My Role as Team Lead
This project highlights my ability to manage development cycles and coordinate a technical team:

* **Project Architecture:** Established the core file structure and enforced BEM methodology for scalable and maintainable CSS.

* **Code Review:** Conducted regular reviews of team members' code to ensure semantic integrity and high quality.

* **Git Management:** Managed the branching strategy, overseen merges, and resolved complex conflicts.

* **Coordination:** Assigned tasks, set deadlines, and provided technical guidance to ensure a cohesive final product.

## 🚀 Key Features
* **Pixel Perfect UI:** Meticulous implementation based on professional Figma layouts.
* **Fully Responsive:** Seamlessly optimized for all devices (Mobile, Tablet, Desktop) using Flexbox and CSS Grid.
* **Clean & Semantic:** Built with HTML5 best practices for improved SEO and accessibility.
* **Smooth Interactions:** Custom navigation, modal windows, and refined hover effects.
